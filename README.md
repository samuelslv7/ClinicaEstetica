# ClinicaEstetica
Desafio prático de um sistema de agendamento para o processo seletivo da COMPEX

## Sobre o Projeto
O objetivo do sistema é organizar a gestão de uma clínica de estética fictícia, automatizando o cadastro de clientes, a disponibilização de horários e os agendamentos, evitando choques de horários.

## Tecnologias Utilizadas
* **Linguagem:** Python
* **Framework:** Django
* **Banco de Dados:** SQLite
* Git / GitHub

## Funcionalidades
* Cadastro de clientes

* Cadastro de horários disponíveis

* Agendamento de horário para cliente

* Cancelamento de agendamento

* Validação para impedir dois agendamentos no mesmo horário

* Tela com listagem dos próximos agendamentos
